# Open Math Problem Lists

开放数学问题数据库、专题题单、形式化猜想库和相关社区入口汇总。

> 最后核验：2026-09-02  
> 本目录只汇总集中收录多个研究级开放问题的公开资源，不对其中每一道题的当前状态作背书。使用前请回查原始论文、维护者说明或固定版本仓库。

## 社区与发现入口

- [MathOverflow: open-problems](https://mathoverflow.net/questions/tagged/open-problems?sort=active)：研究数学问题、已知结果和参考文献讨论。
- [MathOverflow: reference-request](https://mathoverflow.net/questions/tagged/reference-request?sort=active)：寻找专题问题列表和最新文献。
- [Operations Research Stack Exchange: open-problem](https://or.stackexchange.com/questions/tagged/open-problem)：运筹学问题和讨论。
- [arXiv: “open problems” 搜索](https://arxiv.org/search/?query=%22open+problems%22&searchtype=all)：发现新发布的专题问题论文和工作坊题单。
- [arXiv: “problem list” 搜索](https://arxiv.org/search/?query=%22problem+list%22&searchtype=all)：查找以问题列表为主题的论文。

## 使用提示

- 研究机构题单、领域编辑维护题单、提出者原始论文和固定版本仓库通常具有更高权威度。
- 聚合数据库、Wikipedia、MathOverflow 和搜索页面适合发现线索，但不能单独证明问题仍然开放。
- AI 平台、机器生成状态、个人网站和多年未更新的 Wiki 需要额外复核。
- “Lean 已通过”只说明给定形式化陈述被证明，仍需确认该陈述与原问题一致。
- 发现“已解决”或“已反驳”标记时，应核对论文、同行审查、专家确认和适用范围。
